# Ransomware Analysis

Projeto desenvolvido durante meus estudos de Cybersecurity para analisar como um ataque de ransomware pode ocorrer, seus possíveis impactos e algumas medidas de prevenção.

## Objetivos

- Entender o funcionamento de um ataque de ransomware
- Identificar possíveis vetores de ataque
- Analisar os impactos do ataque
- Apresentar medidas básicas de prevenção e incident response
